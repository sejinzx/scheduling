# Scheduling Project

React와 Spring Boot를 활용한 일정 관리 웹 애플리케이션입니다.

## 프로젝트 소개
- 진행 기간 : 2026.04.28 ~ 진행 중
- 개발 인원 : 1인 개인 프로젝트
- 프로젝트 목표 :
  - 일정 관리 기능 구현
  - React와 Spring Boot 연동 경험
  - REST API 설계 및 CRUD 학습
  - Docker 기반 개발 및 실행 환경 구성 경험
  - 프론트엔드와 백엔드 분리 구조 이해

## 기술 스택

### Backend
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- H2 Database
- Swagger(OpenAPI)

### Frontend
- React
- JavaScript
- Axios
- React Router DOM
- React Calendar

### DevOps / Tools
- Docker
- GitHub
- Gradle

## 주요 기능
- 일정 등록
- 일정 수정 및 삭제
- 캘린더 기반 일정 조회
- REST API 연동
- Swagger 기반 API 테스트
